# ZADA Login kit — for coding agents other than Claude Code

To add "Log in with ZADA" to a project, read and follow
`plugins/zada-login/skills/zada-login/SKILL.md` (rules, fixed endpoint values, what to ask the user),
use `plugins/zada-login/skills/zada-login/reference/express-example.js` as the reference flow, and
finish by running `plugins/zada-login/skills/zada-login/scripts/verify.sh <client_id> <callback>`.

The full human guide is `docs/zada-login.md`.
